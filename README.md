## Sales Analysis: Declining-Sales-of-Helicopter-Seats (June - December 2024)
There has been a steady decline in Seats on Non-Scheduled Helicopter Flights to Tourist Sites in Nigeria since June 2024.
## Project Overview
This project investigates the declining number of passengers for a helicopter company offering non-scheduled charter flights to holiday resorts in Nigeria. The aim is to identify trends, uncover potential causes, and provide actionable insights to address this issue.

## Scope
- Analyze passenger trends over the past six months (June to December 2024).
- Identify factors contributing to the decline.
- Propose data-driven recommendations to mitigate the issue.

## Methodology
1. **Data Collection**: Gather data on passenger numbers for the specified period.
2. **Data Cleaning**: Ensure data accuracy and consistency.
3. **Exploratory Data Analysis (EDA)**: Visualize and analyze trends.
4. **Insight Generation**: Identify patterns and correlations.
5. **Reporting**: Summarize findings and recommendations.

## Data Source
The data is a simulated dataset representing the number of passengers from June to December 2024.
